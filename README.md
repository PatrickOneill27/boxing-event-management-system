# Boxing Event Management System

A Linux Shell Scripting application for managing boxing members, events, and fights using CSV-based data storage.

## Features

- Member management
- Event management
- Fight scheduling
- Search functionality
- Validation and error checking
- Reporting features
- CSV file storage

## Technologies

- Bash Shell Scripting
- Linux
- CSV Data Files



## How to Run Locally

### Prerequisites

- Linux, macOS, or Git Bash on Windows
- Bash shell installed

### Clone the Repository

```bash
git clone https://github.com/PatrickOneill27/boxing-event-management-system.git
```

```bash
cd boxing-event-management-system
```

### Make the Script Executable

```bash
chmod +x src/main.sh
```

### Run the Application

```bash
./src/main.sh
```

### Expected Result

The Boxing Event Management System will launch in the terminal and provide menu-driven functionality for:

- Managing members
- Managing events
- Managing fights
- Validation and error checking
- Search functionality
- Reporting features

### Data Files

The application stores data in CSV files located in the `data/` directory:

- `members.csv`
- `events.csv`
- `fights.csv`

These files should remain in their original location for the application to function correctly.
